# Simulation Improvements

This document contains suggested improvements for the simulation.

## Issues

These are some issues which you can address during your project:

- A synchronization method, since module processes may run at arbitrary times, chosen by the OS scheduler.
- Pausing for a long time may crash the simulation.

## Features

These are some features which you can add or improve during your project:

- An improved event generator with support for realistic airport schedules.
- Panning the view in the visualization.
- Adding tubs or planes at will by clicking a module in the visualization.
- Importing config files, to avoid having to restart the simulation GUI.
- Integration tests using the module process.
