# Quercus Router Twin

The repository for the Quercus Airport Router App Digital Twin.

## Requirements
- Ubuntu 24 or higher, Debian 13 or higher

## Installation
All installation is handled in the `run` script. To allow you to run the `run` script, use the following command:

```sh
chmod +x ./run
```

## Usage
Run the project with:

```sh
./run
```

## Support
In case you encounter any problems, send an email to `r.verstappen@student.tue.nl`. This email should contain as much relevant information as possible, including your implementation of the router.

## Contributing
If you make improvements to the digital twin for your project, you are free to contribute these changes to the actual code repo. Any merge requests will be thoroughly reviewed before merging, so make sure you are willing to change your code before opening one.
